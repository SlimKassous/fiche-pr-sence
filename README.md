# Générateur Fiche de Présence • Success Driving School Geneva 🇨🇭

Application web moderne, fluide et autonome pour la génération instantanée de fiches de présence officielles pour auto-école (Sensibilisation, Premiers Secours, Cours Moto 12h & 4h, Théorie).

## 🚀 Accès direct en ligne (GitHub Pages Gratuit)
> **Lien public officiel :** `https://slimkassous.github.io/success-driving-presence/`

---

## ✨ Fonctionnalités Clés
- **Navigation en 3 étapes guidées** :
  1. *Choix du cours et de la session* (vue semaine courante neutre avec filtres langue & type de cours, ou sélection par type).
  2. *Récapitulatif visuel élégant* (moniteur certifié avec photo, dates, horaires, agence).
  3. *Gestion des élèves et émargement* (saisie manuelle ou ajout de lignes vierges).
- **Génération PDF 100% Officielle Suisse en Français** :
  - Mise en page conforme paysage A4 avec logo officiel noir haute résolution.
  - Signatures dynamiques adaptées au nombre de parties de cours (1, 2 ou 3 jours).
  - N° Registre ou Adresse selon le type de cours.
  - Pied de page officiel avec drapeau suisse 🇨🇭 et horodatage Europe/Zurich.
- **Zéro dépendance serveur** : fonctionne 100% côté client en HTML/JS vanilla.

---

## 🛠️ Déploiement GitHub Pages
Ce dépôt utilise GitHub Actions pour un déploiement automatique sur GitHub Pages dès chaque `push` sur la branche `main`.
